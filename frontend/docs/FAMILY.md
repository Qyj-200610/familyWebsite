## 4. 页面展示规则

| 规则 | 说明 |
|------|------|
| 姓名显示 | 页面所有节点 **统一使用姓名缩写**（如 `Lhf`、`Qyj`） |
| 性别标识 | 头像配色区分 — 绿色渐变 = 男，橙色渐变 = 女 |
| 称谓显示 | 节点中括号标注辈分称谓（如"外婆"、"本人"） |
| 配偶展示 | 💍 图标 + 配偶名缩写，并排显示在节点中 |
| 折叠交互 | 每个有后代的节点可点击 `－` 收起分支 / `＋` 展开分支 |
| 视频预览 | 点击在线成员（🟢）头像可跳转到视频预览页面，支持摄像头 + 投屏 + 录屏功能（新增于 2026-07-30） |
| 离线提示 | 点击离线成员（🔴）头像会弹出 Toast 提示当前离线 |
| 在线状态指示器 | 每个成员姓名旁显示绿色脉冲圆点（在线）或灰色圆点（离线），通过后端 `/api/family/status` 接口获取。已登录用户若其用户名匹配家族成员名，该成员显示为在线 |

### 4.1 视频预览功能（`/family-tree/video`）

视频预览页面通过家谱图中点击在线成员头像进入，URL 形如 `/family-tree/video?name=<成员名>`。

| 功能 | 说明 |
|------|------|
| 入口 | 仅在线成员（🟢）可点击进入；离线成员点击后弹出 Toast 提示 |
| 摄像头 | 请求浏览器摄像头权限（`getUserMedia`），实时显示视频流 |
| 投屏 | 使用 `getDisplayMedia` API 捕获屏幕内容，替代摄像头画面 |
| 录屏 | 使用 `MediaRecorder` API 录制当前视频流（WebM 格式），录制完成后可下载 |
| 返回 | 按 `ESC` 键或点击返回按钮退出视频页，自动释放摄像头/屏幕资源 |
| 认证 | 需要登录才能访问，未登录自动重定向到 `/login` |
