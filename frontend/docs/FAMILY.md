## 4. 页面展示规则

| 规则 | 说明 |
|------|------|
| 姓名显示 | 页面所有节点 **统一使用姓名缩写**（如 `Lhf`、`Qyj`） |
| 性别标识 | 头像配色区分 — 绿色渐变 = 男，橙色渐变 = 女 |
| 称谓显示 | 节点中括号标注辈分称谓（如"外婆"、"本人"） |
| 配偶展示 | 💍 图标 + 配偶名缩写，并排显示在节点中 |
| 折叠交互 | 每个有后代的节点可点击 `－` 收起分支 / `＋` 展开分支 |
| 在线状态指示器 | 每个成员姓名旁显示绿色脉冲圆点（在线）或灰色圆点（离线），通过后端 `/api/family/status` 接口获取。已登录用户若其用户名匹配家族成员名，该成员显示为在线 |
