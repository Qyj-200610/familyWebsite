================================================================
                   项目启动指南
================================================================

项目技术栈：React 19 + TypeScript 6 + Vite 8
（每次发布的文件均以 dist 命名）


一、如何看到页面
----------------------------------------------------------------

1. 前往 VSCode 官网下载并安装 VS Code。

2. 打开 VS Code，点击右侧扩展商店图标（"田"字状，即右上角旋转 45° 的方块图标）。

3. 在搜索框中输入 "Live Server" 并安装该插件。
   （如果英文界面看不懂，建议再装一个简体中文语言包插件。）

4. 安装完成后，点击 Live Server 的"启动"按钮。

5. 找到项目中的 index.html（主页），右键选择 "Open with Live Server"，
   即可在浏览器中看到页面。


二、如何修改页面
----------------------------------------------------------------

直接让 AI 辅助修改即可。


三、如何看到修改之后的页面
----------------------------------------------------------------

1. 检查 Node 环境：

   按 Ctrl+J 打开终端，输入以下命令检查 Node 是否安装：

       node -v
       或
       node --version

   如果报错，说明尚未安装 Node，请前往官网下载。
   推荐下载 .msi 结尾的安装包（如果想自己配置环境变量，可下载 .zip 版本）。

2. 验证环境变量：

   安装完成后回到 VS Code，重新打开终端，依次输入：

       node -v
       npm -v
       或
       node --version
       npm --version

   两条命令均能显示版本号，则说明环境变量配置成功。

3. 启动开发服务器：

   在项目根目录下，终端中输入：

       npm run dev

   启动成功后会出现一个本地地址，例如：

       http://localhost:5173/

   Ctrl+左键点击即可在浏览器中打开；如果无法点击，直接复制到浏览器地址栏即可。
   （默认端口为 5173；若该端口被占用，会自动顺延为 5174、5175，以此类推。）
